<h1 align="center">RunMMO</h1>

<p align="center">
Ein transparentes Overlay für TikTok-Live-Streams. Zeigt eine Tempo-Leiter von 1 bis 12 km/h auf dem Stream — die Zuschauer schicken Geschenke, und der Streamer klettert die Leiter hoch.
</p>

<p align="center">
Für Windows und macOS.
</p>
